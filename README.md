# Samuele Scaglioni - Personal Website

This repository hosts my personal academic website, built with HTML and CSS and published through GitHub Pages.

Website: [https://samuelescaglioni.github.io](https://samuelescaglioni.github.io)

## About

I am an incoming Master of Arts student in Economics at the University of Chicago and an Analyst at the European Central Bank. My research interests include macro-finance, banking, financial stability, stress testing, credit risk, political economy, causal machine learning, and applied econometrics.

## Website structure

- `index.html` - homepage
- `research.html` - working papers and work in progress
- `cv.html` - CV page
- `projects.html` - selected projects
- `contact.html` - contact information
- `styles.css` - original website styling
- `images/` - profile and website images
- `files/` - CV and research PDFs

Professional project descriptions are kept at a high level and do not include confidential or internal material.
